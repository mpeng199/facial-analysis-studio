Pipeline (the five added 2026-07-21): the published *_10pct.obj → trimesh →
scaled mm→m, recentred with the base at y=0 and the figure centred in x/z →
`gltf-transform draco --quantize-position 14`. Full scan resolution is kept
(210k–290k triangles each); Draco takes each file from ~5 MB to ~400 KB.
None of the scans carry UVs or usable normals — never give the figure
material a map, and compute vertex normals on load.

discobolus.glb predates that pass and is still the uncompressed, MILLIMETRE-
scale export the Void centrepiece hard-codes (scale 4.9/1682). The niche code
fits every figure from its own bounding box, so it does not care about units.
